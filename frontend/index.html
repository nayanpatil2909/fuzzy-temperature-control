🤔 Why Fuzzy Logic? 💡
❌ Threshold Controller (ON/OFF)
  • ▸ Binary decision: fully ON or fully OFF
  • ▸ Fixed static threshold (e.g. >26°C → 100% cooling)
  • ▸ No awareness of rate of temperature change
  • ▸ Abrupt power switching → compressor wear
  • ▸ Overshoots setpoint → uncomfortable oscillation
  • ▸ Cannot handle overlapping linguistic conditions
✅ Mamdani Fuzzy Logic Controller
  • ▸ Gradual, proportional output (0–100%)
  • ▸ Handles linguistic terms: "slightly hot", "very hot"
  • ▸ Combines error AND rate of change (Δe)
  • ▸ Overlapping MFs produce smooth control transitions
  • ▸ Humidity modifier adapts to perceived comfort
  • ▸ Interpretable: every decision traceable to a rule
Key Insight for Viva: A threshold controller asks "Is the room hot?" (yes/no). A fuzzy logic controller asks "How hot is the room, and how quickly is it getting hotter?" — producing a nuanced, proportional response that mimics expert human judgment rather than a simple switch.

Sign Convention
e = T_target − T_current
e < 0 → room too HOT → more cooling
e > 0 → room too COLD → less cooling
e ≈ 0 → at setpoint → maintain
Centroid Formula
u* = Σ(uᵢ · μ_agg(uᵢ)) / Σ(μ_agg(uᵢ))
where uᵢ ∈ [0, 100] (201 discrete points)
μ_agg = max of all clipped output MFs
Humidity Modifier
m = Σ(μ_label × factor_label) / Σ(μ_label)
Low = 0.85 · Medium = 1.00 · High = 1.15
Final = clip(raw × m, 0, 100)
Fuzzy Set
A set where elements have a degree of membership between 0 and 1, rather than a crisp yes/no. Allows gradual transitions between categories (e.g., "slightly hot").
Membership Function (MF)
A mathematical function that maps a crisp input to a membership degree [0,1]. This project uses triangular (trimf) and trapezoidal (trapmf) MFs.
Fuzzification
The process of converting a crisp numeric input (e.g., error = −8°C) into fuzzy membership degrees for each linguistic set (NB=0.65, NS=0.35, ...).
Rule Base
A set of IF–THEN rules that encode expert knowledge. Here: 25 rules for 5 error × 5 rate-of-error combinations. E.g., "IF e=NB AND Δe=ZE THEN Cooling=VH".
Mamdani Inference
A fuzzy inference method where AND is computed as min(μ₁, μ₂) and the rule implication clips the output MF at the firing strength. Output is a fuzzy set.
Aggregation
Combining all activated rule outputs into a single fuzzy set using the maximum operator: μ_agg(u) = max over all active rules of the clipped output MF.
Defuzzification
Converting the aggregated fuzzy output back to a single crisp number. This project uses the Centroid method (Center of Gravity).
Centroid Method
u* = Σ(u·μ(u)) / Σ(μ(u)) — the "center of mass" of the aggregated fuzzy output curve. Produces a smooth, proportional crisp output.
